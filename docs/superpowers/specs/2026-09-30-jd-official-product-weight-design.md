# 京东散单时效产品与重量字段调整设计

## 背景

京东散单官网模板当前列表展示“产品类型”和“件数”，导出配置中虽然包含“重量(kg)”，但没有对应字段映射。文本识别结果也不包含重量字段，支付方式仅在寄件人配置中存在支付方式时才会填充。

为统一京东散单官网模板的字段语义，需要将产品字段改为“时效产品”，新增重量字段并移除原有“件数”字段，同时为文本识别补充京东散单专属默认值。

## 目标

仅在 `JD_OFFICIAL` 模板下实现以下行为：

1. 列表表头“产品类型”改为“时效产品”。
2. 列表表头“件数”改为“重量（kg）”。
3. 导出 Excel 的“时效产品”下拉框只保留“生鲜标快”和“生鲜特快”。
4. 新增独立 `weight` 字段，导出中的“重量(kg)”读取该字段。
5. 文本识别未识别到重量时，默认填入 `1`。
6. 文本识别未识别到支付方式时，默认填入“寄付现结”。

## 非目标

- 不修改京东月结模板和其他模板的列表、导出及识别默认值。
- 不新增重量文本解析规则，本期只提供默认值。
- 不从历史未导出数据中自动迁移原有“件数”值。
- 不修改支付方式配置弹窗及其他寄件人配置逻辑。

## 字段规则

| 场景 | 字段 | 规则 |
| --- | --- | --- |
| 列表展示 | 时效产品 | 替代原“产品类型”，继续映射到 `delivery_product` |
| 列表展示 | 重量（kg） | 替代原“件数”，映射到新增的 `weight` |
| 导出 | 时效产品 | 导出 `delivery_product`，下拉选项为“生鲜标快、生鲜特快” |
| 导出 | 重量(kg) | 导出 `weight` |
| 文本识别 | 重量 | 空值时默认 `1` |
| 文本识别 | 支付方式 | 空值时默认“寄付现结” |

原“件数”不再出现在京东散单官网模板的列表和导出分类中，也不再从 `item_count` 导出。

## 实现设计

### 模板配置

在 `app_config.json` 的 `JD_OFFICIAL` 配置中调整：

- `list_headers`：将“产品类型”改为“时效产品”，将“件数”改为“重量（kg）”。
- `export_categories`：将必填项中的“产品类型”改为“时效产品”，保留“重量(kg)”，并从其他分类中删除“件数”。
- `dropdown_options`：将下拉字段名改为“时效产品”，选项固定为 `["生鲜标快", "生鲜特快"]`。

### 字段模型

在 `template_manager.empty_fields_dict()` 中新增 `weight` 空字段，保证识别、持久化和导出使用同一数据结构。

在 `main.App._field_key()` 中增加以下表头映射：

- `重量（kg）` -> `weight`
- `重量(kg)` -> `weight`

保留“时效产品” -> `delivery_product` 的现有映射。

### 识别默认值

在 `main.App._merge_fields()` 完成现有寄件人、温层、支付方式和流向产品合并后，针对 `JD_OFFICIAL` 补充模板默认值：

- 当 `weight` 为空时设置为字符串 `"1"`。
- 当 `payment_method` 为空时设置为“寄付现结”。

默认值只影响京东散单官网模板，不写入识别层或全局字段模型，避免影响其他模板。

### 数据流

1. `recognize_batch()` 返回识别字段。
2. `_merge_fields()` 合并寄件信息、模板默认重量和默认支付方式。
3. `_append_row()` 使用当前模板表头构建列表行。
4. 导出时按 `export_categories` 展平表头，并通过 `_field_key()` 读取 `weight`、`delivery_product` 等字段。
5. `write_export_excel()` 根据“时效产品”表头名挂载限定下拉选项。

## 错误处理

- 识别文本没有重量：静默填充 `1`，不提示。
- 识别文本没有支付方式：静默填充“寄付现结”，不提示。
- 用户手动编辑列表中的重量单元格：沿用现有单元格映射逻辑写入 `weight`。
- 历史数据没有 `weight`：读取时保持空值；后续重新识别的新数据按默认值填充。

## 测试设计

补充或调整聚焦测试，覆盖以下分支：

1. `JD_OFFICIAL` 列表表头包含“时效产品”和“重量（kg）”，且不再包含“产品类型”和“件数”。
2. 导出分类包含“时效产品”和“重量(kg)”，且不再包含“件数”。
3. 导出下拉选项只包含“生鲜标快”和“生鲜特快”。
4. `_field_key()` 能将“重量（kg）”“重量(kg)”映射到 `weight`。
5. `_merge_fields()` 在京东散单官网模板下为空重量和空支付方式补充 `1` 和“寄付现结”。
6. 已有重量或支付方式时不被默认值覆盖。
7. 京东月结模板不应用京东散单官网模板的默认值。

## 验收标准

- 切换到京东散单官网模板时，列表显示“时效产品”和“重量（kg）”。
- 京东散单官网模板导出文件不再包含“件数”列。
- 导出“时效产品”列下拉框仅有“生鲜标快”和“生鲜特快”。
- 文本识别生成的京东散单数据默认重量为 `1`、支付方式为“寄付现结”。
- 其他模板行为保持不变。
