# 京东月结模板单行表头导出设计

## 背景

“一键保存”当前通过 `main.App._export_excel()` 读取当前模板的导出字段，再调用
`excel_exporter.write_export_excel()` 生成 Excel。

导出器目前固定生成双行表头：

1. 第 1 行为分类标题，并按分类合并单元格。
2. 第 2 行为字段标题，并按分类设置底色。
3. 数据从第 3 行开始。
4. 下拉验证从第 3 行开始。
5. 冻结窗格为 `A3`。

该格式适用于京东散单官网模板，但京东月结模板需要单行字段表头。

## 目标

- 选择京东月结模板时，导出单行字段表头。
- 月结模板的数据从第 2 行开始。
- 月结模板保留各字段当前的分类底色。
- 月结模板保留下拉框，并按新的数据起始行调整数据验证范围。
- 选择京东散单官网模板时，继续导出原有双行表头文件。
- 保留现有导出字段顺序、列宽、保存流程和调用兼容性。

## 非目标

- 不修改模板字段配置或字段映射。
- 不修改一键保存的校验、文件命名和保存目录逻辑。
- 不调整 UI、模板数据持久化或模板切换逻辑。
- 不把模板格式规则扩展为通用配置系统。

## 方案

在导出器增加可选参数：

```python
write_export_excel(
    file_path,
    categories,
    rows,
    dropdown_options=None,
    single_row_header=False,
)
```

`main.App._export_excel()` 根据当前模板显式传入：

```python
single_row_header=(self._template_key == "JD_MONTHLY")
```

现有调用方不传该参数时继续生成双行表头，保持向后兼容。

## 行为设计

| 行为 | 京东月结模板（单行） | 京东散单官网模板（双行） |
| --- | --- | --- |
| 分类标题 | 不生成 | 第 1 行 |
| 字段标题 | 第 1 行 | 第 2 行 |
| 数据起始行 | 第 2 行 | 第 3 行 |
| 分类底色 | 保留 | 保留 |
| 合并单元格 | 不生成 | 第 1 行按分类合并 |
| 下拉验证起始行 | 第 2 行 | 第 3 行 |
| 下拉验证结束行 | 第 1001 行 | 第 1002 行 |
| 冻结窗格 | `A2` | `A3` |
| 列宽 | 保持不变 | 保持不变 |

导出器按模式计算表头行、数据起始行、冻结窗格和下拉验证范围：

- 单行模式：`header_row = 1`、`data_start_row = 2`、`freeze_panes = "A2"`。
- 双行模式：`header_row = 2`、`data_start_row = 3`、`freeze_panes = "A3"`。
- 单行模式不执行分类标题写入和合并操作。
- 字段标题样式继续使用字段所属分类的颜色和边框配置。
- 下拉验证保留 1000 行，仅根据数据起始行动态平移。

## 错误处理

- 不增加新的异常类型或配置迁移。
- 未传 `single_row_header` 时默认使用双行模式。
- 未知模板 key 不会触发单行模式；只有 `JD_MONTHLY` 显式启用。
- 原有字段为空、保存路径取消、必填校验失败等行为保持不变。

## 测试设计

### 导出器测试

新增或扩展单元测试，覆盖以下断言：

1. 单行模式第 1 行为字段标题。
2. 单行模式第 1 行不存在分类标题和合并单元格。
3. 单行模式第 2 行开始写入数据。
4. 单行模式冻结窗格为 `A2`。
5. 单行模式字段底色仍来自对应分类颜色。
6. 单行模式下拉验证作用于第 2 行至第 1001 行。
7. 双行模式继续使用第 1 行分类、第 2 行字段、第 3 行数据。
8. 双行模式继续存在分类合并单元格和 `A3` 冻结窗格。
9. 双行模式下拉验证继续作用于第 3 行至第 1002 行。

### 主流程测试

补充 `main.App._export_excel()` 的调用参数测试：

1. `JD_MONTHLY` 调用导出器时传入 `single_row_header=True`。
2. `JD_OFFICIAL` 调用导出器时传入 `single_row_header=False`。
3. 其他参数仍按当前逻辑传递，导出成功后继续清空列表和持久化状态。

## 验收标准

- 京东月结模板导出的 Excel 中，第 1 行为字段标题，第 2 行开始为数据。
- 京东月结模板导出文件中没有分类合并标题。
- 京东月结模板字段底色和下拉框仍存在。
- 京东散单官网模板导出格式与当前版本一致。
- 现有及新增单元测试全部通过。
